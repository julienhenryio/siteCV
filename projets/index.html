Hors ligne

Ce qui ne s'ouvre pas dans un navigateur

L'essentiel de ce que je fabrique ne tient pas dans une page web : des workflows n8n auto-hébergés, des agents dirigés depuis Claude Code ou OpenCode, un agent Hermes qui tourne sur mon propre VPS, des interfaces internes taillées pour un usage unique.

Ce ne sont pas des produits et ils n'ont pas vocation à le devenir. C'est mon terrain d'essai : j'y casse les choses avant de les proposer à un client. Une bonne partie de ce que je déploie en mission a d'abord tourné là, en moins propre.
